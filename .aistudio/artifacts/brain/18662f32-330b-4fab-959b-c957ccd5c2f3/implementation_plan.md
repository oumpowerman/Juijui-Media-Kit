# ระบบตั้งค่าไอคอน อิโมจิ และชื่อแท็บเบราว์เซอร์ (Custom Browser Tab Favicon, Emoji & Title Studio)

เพิ่มฟีเจอร์ตั้งค่า **ไอคอนหน้าแท็บเบราว์เซอร์ (Favicon)** และ **ชื่อแท็บเบราว์เซอร์ (Browser Tab Title)** เมื่อเปิดเว็บไซต์บนคอมพิวเตอร์ โดยสามารถปรับแต่งได้เองทันทีผ่านหน้า Admin รองรับทั้งการเลือกอิโมจิ การวางลิงก์รูปภาพ (รวมถึง Google Drive) และการอัปโหลดไฟล์รูปภาพจากคอมพิวเตอร์ พร้อมภาพตัวอย่างจำลองแท็บเบราว์เซอร์แบบสด (Live Browser Tab Preview) และค่าเริ่มต้นในหน้าเว็บหลัก

---

## การตัดสินใจที่ได้รับการยืนยันจากคุณ (User Review & Confirmed Decisions)

> [!IMPORTANT]
> แผนนี้ออกแบบตามตัวเลือกที่คุณยืนยัน เพื่อให้คุณเปลี่ยนไอคอนและชื่อแท็บเบราว์เซอร์ได้เองทุกเมื่อโดยไม่ต้องแก้ไขโค้ด

- **วิธีจัดการไอคอนแท็บ (Favicon & Tab Management)**: **ตั้งค่าได้เองในหน้า Admin ทั้งเลือกรูปและอิโมจิ** — มีแผงควบคุมเฉพาะในหมวดข้อมูลโปรไฟล์และรูปภาพของหน้า Admin
- **รูปแบบการใส่รูปไอคอนที่รองรับ (Supported Icon Sources)**: **รองรับครบทั้ง 3 รูปแบบ** ได้แก่ (1) วางลิงก์รูปภาพหรือลิงก์แชร์ Google Drive (2) อัปโหลดไฟล์รูปจากเครื่องคอมพิวเตอร์โดยตรง และ (3) เลือกจากคลังอิโมจิยอดนิยมหรือพิมพ์อิโมจิเอง
- **การปรับแต่งชื่อแท็บ (Browser Tab Title)**: **แก้ไขข้อความชื่อแท็บเบราว์เซอร์ได้เองในหน้า Admin** — สามารถกำหนดข้อความบนแท็บ (เช่น `✨ JUIJUI Media Kit 2026 — เรทการ์ดและพอร์ตโฟลิโอ`) และเห็นผลลัพธ์บนแท็บเบราว์เซอร์ทันที

## 1. ภาพรวมและแนวคิดหลัก (Overview & Core Concept)

- **สิ่งที่ระบบนี้ทำ**:
  1. กำหนดไอคอนเริ่มต้น (Default Favicon) ให้กับหน้าเว็บทันทีตั้งแต่เปิดเข้าใช้งานครั้งแรก (ไม่ปล่อยให้เป็นไอคอนลูกโลกสีเทาว่างๆ ของเบราว์เซอร์)
  2. เพิ่มแผง **"ตั้งค่าแท็บเบราว์เซอร์บนคอมพิวเตอร์ (Browser Tab Icon & Title)"** ในหน้า Admin เพื่อให้คุณสลับโหมดไอคอนแท็บได้ 4 โหมด:
     - **โหมดอิโมจิ (Emoji Icon)**: เลือกอิโมจิหรือพิมพ์อิโมจิที่ชอบ ระบบจะแปลงเป็น SVG Favicon ความคมชัดสูงแสดงผลบนแท็บเบราว์เซอร์ทันที
     - **โหมดรูปโปรไฟล์ช่อง (Use Channel Avatar)**: ดึงรูปโปรไฟล์หลักของครีเอเตอร์มาตัดเป็นไอคอนวงกลม/สี่เหลี่ยมมนบนแท็บอัตโนมัติ
     - **โหมดลิงก์รูปภาพ / Google Drive (Custom Image URL)**: วางลิงก์รูปภาพหรือลิงก์ Google Drive หรือระบุพาธไฟล์ในโฟลเดอร์ `public/`
     - **โหมดอัปโหลดไฟล์จากเครื่อง (Upload Image File)**: เลือกไฟล์ PNG, JPG, WEBP หรือ SVG จากคอมพิวเตอร์ ระบบจะย่อขนาดเป็นไอคอนมาตรฐาน `64×64px` อัตโนมัติเพื่อให้โหลดเร็วและบันทึกขึ้น Cloud ได้ทันที
- **กลุ่มเป้าหมายหลัก**: เจ้าของช่องและทีมแอดมินที่ต้องการสร้างภาพจำแบรนด์ระดับมืออาชีพเมื่อลูกค้าหรือเอเจนซี่เปิดแท็บ Media Kit ค้างไว้หลายแท็บในคอมพิวเตอร์
- **คุณค่าหลักที่ได้รับ**: แท็บเว็บไซต์ดูโดดเด่น มีเอกลักษณ์ สังเกตเห็นง่ายท่ามกลางแท็บอื่นๆ ในเบราว์เซอร์ และปรับเปลี่ยนตามแคมเปญหรือเทศกาลได้ตลอดเวลาจากหน้า Admin

## 2. ประสบการณ์ผู้ใช้และการออกแบบภาพลักษณ์ (User Experience & Visual Design)

### ลำดับการใช้งานในหน้า Admin (Key User Flows)
1. **เข้าสู่หน้าตั้งค่า**: เปิดหน้าจัดการข้อมูล (Admin Studio) ไปที่แท็บแรก **"ข้อมูลหลัก & รูปโปรไฟล์"** (แสดงอยู่ในหมวดรูปโปรไฟล์ & ไฟล์ PDF หรือดูทั้งหมด)
2. **ดูตัวอย่างแท็บเบราว์เซอร์แบบสด (Live Desktop Browser Tab Mockup)**:
   - ด้านบนของกล่องตั้งค่าจะมีจำลองแถบแท็บของ Google Chrome / Safari บนคอมพิวเตอร์ แสดงไอคอนที่เลือกคู่กับชื่อแท็บแบบเรียลไทม์
3. **เลือกโหมดไอคอนหน้าแท็บ**:
   - **หากเลือก "อิโมจิ (Emoji)"**: มีปุ่มอิโมจิยอดนิยมให้คลิกเลือกได้ทันที (เช่น `✨`, `🎬`, `🔥`, `💜`, `👑`, `🌟`, `🚀`, `💎`, `🎉`, `📸`) หรือพิมพ์อิโมจิใดก็ได้ในช่องกรอก
   - **หากเลือก "ใช้รูปโปรไฟล์ช่อง"**: ใช้รูปโปรไฟล์ปัจจุบันของช่องมาทำเป็นไอคอนหน้าแท็บในคลิกเดียว
   - **หากเลือก "อัปโหลดรูป / ลิงก์รูปภาพ"**:
     - กดปุ่ม **"เลือกไฟล์รูปจากคอมพิวเตอร์"** เพื่ออัปโหลดรูปโลโก้หรือสติกเกอร์จากเครื่อง
     - หรือวางลิงก์ Google Drive / URL รูปภาพลงในช่องกรอก
     - พร้อมคำแนะนำบอกตำแหน่งชัดเจนว่า หากต้องการนำไฟล์รูปมาวางในโปรเจกต์โดยตรง สามารถนำไฟล์ไปวางไว้ที่โฟลเดอร์ `public/` แล้วพิมพ์ `/ชื่อไฟล์.png` ได้ทันที
4. **ตั้งชื่อแท็บเบราว์เซอร์ (Browser Tab Title)**:
   - ช่องกรอกข้อความชื่อแท็บ พร้อมปุ่มลัดใส่อิโมจินำหน้าชื่อแท็บ และปุ่มคืนค่ามาตรฐาน
5. **บันทึกและซิงค์อัตโนมัติ**:
   - ทันทีที่ปรับเปลี่ยน แท็บเบราว์เซอร์จริงด้านบนสุดของหน้าจอคอมพิวเตอร์จะเปลี่ยนตามแบบสดๆ และเมื่อกดบันทึก ข้อมูลจะถูกจำไว้ทั้งในเครื่องและบน Cloud Firestore เพื่อให้ลูกค้าทุกคนที่เปิดลิงก์เห็นไอคอนและชื่อแท็บเดียวกัน

## 3. การตัดสินใจเชิงผลิตภัณฑ์และเหตุผลรองรับ (Key Product Decisions & Trade-Offs)

- **การตัดสินใจที่ 1: แปลงอิโมจิเป็น Dynamic SVG Favicon ในหน่วยความจำ**
  - *แนวทางที่เลือก*: สร้าง `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100"><text y=".9em" font-size="90">...</text></svg>` แล้วแปลงเป็น Data URI ผูกเข้ากับ `<link rel="icon">` ใน `<head>`
  - *เหตุผล*: เบราว์เซอร์สมัยใหม่ทุกตัวบนคอมพิวเตอร์ (Chrome, Edge, Firefox, Safari) รองรับ SVG Favicon ทำให้สามารถใช้อิโมจิใดก็ได้เป็นไอคอนหน้าแท็บโดยมีความคมชัดระดับ Vector ไม่แตกเบลอ และไม่ต้องเตรียมไฟล์รูปภาพ
- **การตัดสินใจที่ 2: ระบบย่อขนาดภาพอัตโนมัติเมื่ออัปโหลดจากเครื่อง (Client-Side 64×64 Canvas Compression)**
  - *แนวทางที่เลือก*: เมื่อผู้ใช้อัปโหลดไฟล์รูปจากคอมพิวเตอร์ ระบบจะใช้ HTML5 Canvas ย่อและครอปเป็นขนาด `64×64px` (PNG Data URL ขนาดเล็กเพียงไม่กี่ KB)
  - *เหตุผล*: ป้องกันปัญหาไฟล์ภาพขนาดใหญ่เกินขีดจำกัดของฐานข้อมูล Cloud Firestore และทำให้เบราว์เซอร์โหลดไอคอนหน้าแท็บได้รวดเร็วที่สุด
- **การตัดสินใจที่ 3: รองรับทั้งการตั้งค่าผ่าน Admin และการวางไฟล์ในโฟลเดอร์ `public/`**
  - *แนวทางที่เลือก*: มีทั้งระบบตั้งค่าผ่านหน้าจอ Admin และแสดงกล่องคำแนะนำบอกตำแหน่งโฟลเดอร์ `public/` สำหรับกรณีที่ต้องการวางไฟล์ภาพไว้ในโปรเจกต์โดยตรง
  - *เหตุผล*: ตอบโจทย์ทั้งการใช้งานแบบไม่ต้องแตะโค้ด และการจัดการไฟล์ภาพโดยตรงในโครงสร้างโปรเจกต์

## 4. สถาปัตยกรรมทางเทคนิค (Technical Architecture)

### แผนผังการทำงานของระบบ (System & Data Flow Diagram)

```
┌────────────────────────────────────────────────────────────────────────────┐
│                   Admin Studio (Profile & Identity Tab)                    │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │  Live Desktop Browser Tab Mockup (Chrome/Safari Tab Bar Preview)     │  │
│  ├──────────────────────────────────────────────────────────────────────┤  │
│  │  Mode Selector: [อิโมจิ] [รูปโปรไฟล์ช่อง] [อัปโหลดรูป / ลิงก์รูปภาพ]    │  │
│  │  • Emoji Picker Grid & Custom Emoji Input                            │  │
│  │  • File Uploader (Auto-resize to 64x64 PNG Data URL via Canvas)      │  │
│  │  • Image URL / Google Drive Resolver / Public Folder Path Input      │  │
│  │  • Browser Tab Title Input + Quick Reset                             │  │
│  └──────────────────────────────────┬───────────────────────────────────┘  │
└─────────────────────────────────────┼──────────────────────────────────────┘
                                      │ Updates CreatorProfile State & Cloud
                                      ▼
┌────────────────────────────────────────────────────────────────────────────┐
│                Dynamic Document Head Synchronizer (App Root)               │
│  • Updates `document.title` with custom Browser Tab Title                  │
│  • Resolves active Favicon source (SVG Emoji / 64x64 Data URL / Drive URL) │
│  • Injects & updates `<link rel="icon">` and `<link rel="apple-touch-icon">`│
└────────────────────────────────────────────────────────────────────────────┘
```

### โครงสร้างข้อมูลที่เพิ่มเติมในโปรไฟล์ครีเอเตอร์
- เพิ่มฟิลด์การตั้งค่าแท็บเบราว์เซอร์ในข้อมูลครีเอเตอร์:
  - `faviconMode`: โหมดการแสดงผล (`'emoji'` | `'avatar'` | `'custom'`)
  - `faviconEmoji`: อิโมจิที่ใช้แสดงเป็นไอคอนแท็บ (ค่าเริ่มต้นเช่น `'✨'` หรือ `'🎬'`)
  - `faviconUrl`: ลิงก์รูปภาพ, พาธไฟล์ในโฟลเดอร์สาธารณะ หรือ Data URL จากการอัปโหลด
  - `browserTabTitle`: ข้อความชื่อแท็บเบราว์เซอร์ที่กำหนดเอง
